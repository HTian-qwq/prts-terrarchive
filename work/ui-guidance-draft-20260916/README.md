## 主要问题

1. 顶部、底部、侧边出现重复导航，入口分散。
2. 调查计数重复，装饰性英文与技术状态占用注意力。
3. 报告和当前浏览的资料缺少主次，调查结束后下一步不明确。
4. 提问框对比过低，文字直接叠在几何背景上，阅读不稳定。
5. 当前资料的标题、翻页、分类与打开入口彼此分离。

## 布局方向

- 顶部统一为调查台、资料库、证据板；会话历史和新建调查位于右上角。
- 左侧保留 3D 档案浏览，底部集中当前资料标题、打开入口、翻页与分类。
- 右侧为浅色、不透明的调查工作区。问题、进度、报告、追问沿同一列排列。
- 调查统计合并为一行。模型与模式配置收进明确标记的“调查设置”。

## 引导随状态变化

| 状态 | 首要动作 | 辅助信息 |
| --- | --- | --- |
| 尚未提问 | 输入问题并开始调查 | 少量可直接使用的示例问题、资料库入口 |
| 调查进行中 | 查看当前调查进度 | 已找到的资料、当前读取内容、停止操作；避免虚构百分比 |
| 调查完成 | 阅读调查报告 | 一行统计、调查过程、继续追问 |
| 阅读与核对 | 点击引用查看对应原文 | 建议右侧保持报告，左侧临时切换原文并定位行号，可返回 3D 浏览 |

草稿展示“调查完成”状态。其他状态沿用同一骨架，避免增加重复的导航层。
