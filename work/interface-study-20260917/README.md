# Rhine Lab · 浮动界面布局提案

2026-09-17 · 独立设计稿，未接入生产界面或 Agent。

## 查看

启动静态服务后打开 `index.html`。例如在此目录运行：

```sh
python3 -m http.server 4241 --bind 127.0.0.1
```

桌面底部的审阅控件可以切换「待开始 / 调查中 / 已完成」三种示例状态，以及轻微视差。输入、资料翻页和展开操作用于体验排版与交互，不发起真实检索。

## 设计意图

保留完整的莱茵生命三维场景、暖白与金属灰配色，以及直接浮在场景上的文字。用共同的对齐线、留白和少量细线组织内容，不增加实色面板、卡片或侧栏。

| 现有问题 | 提案 |
| --- | --- |
| 顶部、左下与右下重复出现地点入口 | 顶部只保留一组场景索引；屏幕边缘提示在悬停或键盘聚焦时出现 |
| 调查状态、问题输入、结果阅读分散 | 右侧同一列随任务阶段变化；输入与当前任务保持在一起 |
| 零值统计、说明、按钮同时争夺注意力 | 待开始仅显示输入；调查中才出现统计和进度；完成后给出报告入口 |
| 资料序号、类别、上下左右箭头分布过远 | 左下把当前资料、阅读原文、翻页和类别合成连续的一组文字 |
| 摘录、会话历史等次要工具常驻 | 收入右上按需展开的文字菜单 |

视觉层级只有三个主要锚点：左上品牌、右侧当前任务、左下当前资料。字号和对比度随主次变化，细小英文仅用于少量编号与定位。

## 动效取舍

建议默认静态，场景切换保留原有平滑过渡。现有三维场景已经有轻微鼠标跟随，暂不增加更强的旋转、文字漂移或多层滚动。

设计稿提供可选的轻微背景位移，用于比较有无动效的观感：最大约水平 6px、垂直 4px；文字和点击位置固定。输入时暂停，触控或系统要求减少动画时关闭。

这个演示使用真实场景的静态截图移动，不代表额外实现了多层三维视差。正式实现应复用场景已有相机逻辑，避免再增加持续渲染。

尊重减少动画偏好的依据：[MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)；交互动效可关闭的设计参考：[W3C Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)。
