# 莱茵生命：阅读返回、调查归属与资料分层

2026-09-21。

## 阅读与返回

- 原文阅读记住打开前的场景、面板、页码、筛选、滚动位置和焦点。Esc、左侧返回、右上返回采用同一路径。
- 搜索结果 → 原文 → 搜索结果；档案目录 → 原文 → 原目录；报告／线索／证据盒 → 原文 → 原调查板上的对应内容。
- 阅读期间 Agent 改用新工作板，不改变这次阅读的来源调查板。切换会话会作废旧返回路径。
- 返回报告后，再关闭报告，焦点仍回到最初打开报告的入口。

## 调查板归属

- 查看中的调查板、Agent 工作板、手动选定的证据盒目标是三个独立状态。
- 每个放入证据盒的入口旁都显示“证据盒归属”。默认跟随工作板；无工作板时使用当前板；无板时明确显示首次放入将新建。
- 可手动选择具体调查板。选择在同一会话内保持，不因浏览别的调查板或 Agent 开新板而改变；换会话重置。
- 写入采用点击当时的目标，异步返回和排队不重定向。目标失效时要求重新选择，不静默写入其他板。
- Agent 的新建／延续仍通过调查工具与 LLM 决策；手动目标选择不绑定 Agent 的工作调查。

## 手动浏览与跟随

- 手动选资料、翻架、发起检索或打开原文，会暂停自动跟随。
- 暂停持续到点击“恢复跟随”，不会在四秒后或下一次工具调用时自动恢复。
- 后台照常检索与读取；界面提示新增查阅次数。恢复时选择最新查阅，清除提示；不会排队回放全部旧查阅。
- 新会话恢复默认跟随模式。

## 线索编辑

- 编辑态是一张放大的线索纸片，与板面共用纸色、类别和强调色；保留线索编号、来源和核验状态。
- 标题与正文直接在纸面编辑，长标题自动换行。输入沿用原有自动保存、冲突检查和撤销历史。
- 编辑纸片优先出现在当前线索旁，仍可拖动上方操作条调整位置；窄屏收到底部并保持在场景标签上层。
- 连线和复制留作轻量操作；尺寸、已有关联及更多属性收在展开项中。
- 输入时按 Esc 也会保存当前草稿并收起编辑，保留调查板位置；输入法组词时的 Esc 不关闭编辑。

## 场景模型切换

- 直接点击可见的档案架（含空托盘）、检索阵列或调查板，切换到对应场景，并沿用镜头转场。
- 鼠标悬停显示手形与目标名称；当前场景中的模型仍执行原有选择、阅读或编辑操作。
- 按真实模型的前后遮挡判断点击，隐藏模型和背景空白不触发切换。拖动、白板编辑、全屏、阅读及转场期间不抢占操作。
- 手动点击模型切换会暂停 Agent 自动跟随，与其他手动浏览入口一致。

## 资料层级和分类

| 位置 | 收录规则 |
| --- | --- |
| 检索阵列 | 本次会话发现的候选资料，可直接阅读或选入证据盒 |
| 档案架 | Agent 实际读过的资料，或用户手动收藏的资料 |
| 调查板旁的重点证据盒 | 所属调查中待核对、待整理的重点材料；不自动代表已读或已证实 |
| 调查板 | 经整理的线索、关系与报告 |

单纯“查得”或“引用”不等同于“已读”。放入证据盒不要求先入架，也不会顺带收藏。
五个内容分类为角色档案、剧情记录、世界资料、时间线、其他资料；本地／云端／网页是独立来源标签。
资料编号基于候选目录，在阅读、引用和收藏后保持一致；架上物理槽位与资料编号分别计算。

### 运行交互回归

先运行 `npm ci` 与 `npm run build:rhine`。七组真实浏览器流程可通过 `npm run test:rhine:flows` 依次运行，每组使用独立测试存储和本地 RPC 服务，无需预先启动预览。

- `PRTS_DSH_SOURCE_DIR`：已构建的 DSH 源码目录，需包含 `packages/storage/storage-domain/lib` 与 `storage-json/lib`。默认使用相邻 portable 仓库的 `.build/dsh-electron`。
- `PRTS_PLAYWRIGHT_MODULE`：可选 Playwright 入口路径；也可在项目或 Host 的依赖中安装 Playwright。
- `PRTS_BROWSER_EXECUTABLE`：可选 Chromium 浏览器路径；或用 `PRTS_BROWSER_CHANNEL` 指定已安装通道。Windows 默认 Edge，其他平台默认 Playwright Chromium。
- 流程截图和测试回执写到忽略的 `work/` 目录。测试使用隔离的示例数据，不读取正式用户资料，也不调用真实模型。

普通 `npm test` 仍独立运行单元与契约测试；需要额外 Host 环境或真实服务的用例按各自条件跳过。
