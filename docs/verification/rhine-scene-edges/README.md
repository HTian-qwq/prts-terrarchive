# 屏幕边缘切换场景

> 验证截图已从仓库及历史中移除，不再归档。以下保留当时的验证方法、数据和截图说明；需要图片时请在本地重新生成。

2026-09-16。屏幕两侧中段增加细箭头、区域编号和目标名称，沿用暖灰与浅香槟配色。
点击左侧前往左邻场景，右侧前往右邻场景；顺序固定为检索阵列、证据板、档案收录架，首尾不循环。
左下角导航继续保留，两种入口共用原有 `setLocation()` 和镜头过渡。

桌面点击区域为 52px 宽，舞台缩放后仍贴住可见窗口边缘；窄屏为 44px 宽，入口稍向上移，避开底部编辑区。
普通按钮支持 Tab、Enter、空格与触摸点击。到达首尾时，不存在的方向隐藏；键盘焦点回到当前区域导航。

只有从边缘按钮开始并正常松开的点击才会切换。拖出再拖回、指针取消、失焦及快速双击不会连续误跳。
纸片移动、缩放和平移仍由画布处理，拖到边缘释放不触发导航；从编辑窗切走时沿用原保存流程。
阅读器、弹窗、模型查看器、白板全屏，以及待放置或连线模式期间隐藏并禁用边缘入口。

实现位于 `ui/rhine/scene-edge-navigation.ts`；入口状态随已有模式更新，不增加渲染器、动画循环或轮询计时器。
点击时再次检查模式与起始目标，全部全局指针监听随组件销毁移除。

## 浏览器检查

构建与 TypeScript 检查通过，7 组浏览器交互检查通过，无页面或控制台错误：

- 三区双向切换、相邻目标文案和首尾边界。
- 双击只前进一站，拖出再返回及取消按压不切换。
- Enter/空格操作及首尾焦点恢复。
- 全屏、搜索弹窗、放置及连线模式阻止边缘导航。
- 切走保存未提交草稿，拖纸片到屏幕边缘不误切。
- 1366px 舞台缩放后入口仍贴边；390px 模拟触摸可切换，宽度保持 44px。
- 阅读及隐藏工作台时入口不可用，所有切换复用原渲染器。
