# 手动证据白板场景验证

2026-09-16 更新。证据白板、检索阵列与档案收录架复用原来的 Three.js 场景、相机和渲染器。
白板沿用原版档案的暖白外壳、暖银灰边缘与淡香槟细节，保留实体图钉和暗红细绳，
底部有笔托、粉笔盒、板擦与加高的落地支脚。照片、装置图纸、观测记录、信号条和短便签采用各自的比例与排版。
纸张带接触阴影、叠页与胶带；纸片支持拖动、编辑、手动关联和资料置入，最多 12 条，按会话保存在浏览器。

## 交互体验修订

本次先操作旧版，再验证修订版。旧版的 Ctrl+Z 无法撤销纸片缩放，连线工具会清除已有选择；
390 × 844 时，纸片中心位于 Y 364–469，编辑抽屉从 Y 309 开始，白板完全被遮住。
见 [旧版手机实拍](experience/before-mobile.png)和[旧版操作数据](experience/before-report.json)。

本次提供纸片右下角直接缩放、选中线索直接连线与复制、40 步撤销/重做、保留选择的工具窗收起。
单击打开编辑，直接拖动只整理位置；移动过的示例也会成为用户线索，清空未编辑示例时保留。
窄屏全屏相机适配抽屉上方的可用区域，按住纸片时保持手势投影，避免取景改变造成跳动。

`test/evidence-board-experience-browser.mjs` 的 12 组浏览器检查已通过，覆盖：

- 正面与斜视、1366px 舞台缩放下的直接尺寸手势，纸片中部移动及 Esc 取消。
- 缩放、移动、新建、复制、删除、文字编辑、连线和清空的撤销/重做；示例身份、来源和红绳端点一致。
- 原生输入框文字撤销、未保存草稿恢复、滑杆按住超过 250ms 后继续调整仍只记一个历史步骤。
- 390px 展开和收起编辑窗、首次从关闭状态拖动纸片时相机稳定，单击仍打开编辑。
- 已移动示例免于清空、会话历史隔离和刷新保存。

缩放预览没有新增纸片纹理上传或纹理分配；示例首次转为用户线索时仍正常更新标记。

## 单张线索大小

选中纸片后，编辑窗的「纸片大小」可用滑杆、加减按钮调整，或点击「原大小」恢复 100%。
通常支持 50%–200%，较大且倾斜的纸片会按板面可用空间限制实际最大倍率；纸片和内容等比变化，红绳端点跟随图钉。
放大靠边纸片时自动调整位置，旧纸片默认 100%，新尺寸随会话保存。

以下为前一轮滑杆缩放记录，其中窄屏遮挡问题已由上方的交互修订处理：
[桌面 150% 实拍](size/01-paper-size-150.png)、[窄屏编辑](size/02-paper-size-mobile.png)与[检查报告](size/report.json)。
`test/evidence-card-size-browser.mjs` 覆盖实时调整、原大小与加减、其余纸片和相机保持、红绳端点、
边界约束、草稿与来源保留、关闭/会话切换/刷新保存、窄屏与无 WebGL 编辑。
连续拖动不会增加纸片纹理更新计数、纹理数量或像素预算；松手或短暂停顿后保存。
示例首次编辑仍按既有规则转为用户线索并更新印刷标记。构建、模型回归与上述浏览器检查通过。

## 当前白板工具

缩放与「全屏」合并为一条贴在白板右上角的薄铭牌。`320 × 45` 的 DOM 通过四角投影矩阵贴合板面，
对应局部 X `[3.67, 7.37]`、Y `[3.80, 4.32]`；文字与按钮命中区域一起服从白板透视及缩放。
只有铭牌离屏时才恢复常规朝向的停靠按钮，返回后重新贴合。
笔托左侧改为 `1.02 × 0.48` 的浅纸色半开小盒，五支粉笔长 `0.40–0.45`、直径约 `0.096`，
沿盒深自然并排，四支暖白、一支暗红；粗糙材质与纸盖上的 `RHINE / CHALK` 字样表现纸盒与粉笔质感。
共有 11 个实体拾取对象，盒中心锚点为 `(-3.8, -4.20, 0.48)`。盒下悬浮标签和矩形 hover 框已经移除，
保留不可见的键盘命中区和真实实体拾取。点击打开单一「整理线索」浮窗，标题栏可以拖动。
点选纸片在同一个浮窗编辑，390 像素窄屏使用底部抽屉；粉笔盒离屏时，板角补出「工具」入口。

浮窗提供短便签、疑问签、资料卡和关键词标签。选择样式后先在板面预览，点击空白处放下，未确认时不写入数据。
短便签与疑问签显示摘要，关键词标签显示一行标题；完整正文、来源和阶段仍保留。旧纸片继续使用原来的尺寸与布局。
选择「红绳连线」后依次点两张纸片，暗红虚线跟随鼠标，确认后形成实体红绳；重复关系和自身关系不会新增。
支持断开关系，并和纸片新增、编辑、移动、缩放等操作共用撤销/重做历史。

证据板画面支持 1–3 倍滚轮缩放，朝鼠标指向的线索靠近，双击空白处恢复全貌。
板角的 `− / 比例 / ＋` 也可缩放，点击比例复位；浮窗滚动与纸片拖动独立，缩放复用现有相机缓动、画质设置和纸片纹理。
左键拖动空白处平移，空格加左键或鼠标中键可从纸片上开始平移；普通左键拖动纸片仍然整理线索位置。
板角的「全屏」切到正面并适配窗口，
暂时收起阵列、档案架和导航，保留当前场景、渲染器和纸片对象；退出后恢复原来的视角。
Esc 依次移开输入焦点、取消放置或连线、收起浮窗、退出全屏，保留已编辑内容。

## 保留的内容、空间与渲染基准

六张初始纸片采用经原文核对的《孤星》剧情改写，可一键清空。具体章节与行号见
[文案核对](../../rhine-lone-trail-copy.md)。纸片宽高缩为上一版的 80%，标题与正文同步收小，板面保留更多空白。
纸片印刷面、胶带和板头铭牌现在复用档案标签的最终分辨率渲染通道，
避免小字经过普通场景缩放和后处理变软。每张纸片共用一份纹理绘制印刷底图和高清层，
处理红线遮挡边缘的白色漏底；保持原来的尺寸、字号、相机和性能档。
见 [清晰度对照与检查](clarity/README.md)。
旧版未编辑示例会按原有身份更新文字，删除的示例不会恢复；从上一版升级时，
纸片位置和旋转继续保留，用户已编辑的内容不被替换。Agent 写入与新的资料归档协议尚未接入。

白板中心位于 `(29.7, 4.8, -8)`，处在检索阵列和档案架之间，绕 Y 轴 `-34°` 且竖直放置。
左下阵列在前景，白板在上中部，档案架在右下稍远处。支脚落在原地面 `Y=-4.63`，
避开阵列末端和档案架。白板镜头距离为 80，其余区域沿用原视角，透视自然收束。
三个区域持续留在场景内；镜头按「检索阵列 → 证据板 → 档案收录架」连续经过，
中心、取景范围和距离在各段平滑过渡。
