# 证据板清晰度

2026-09-12。纸片缩小后，普通场景中的印刷面经 1 倍分辨率、SMAA 和输出转换，
再放大到最终画面，小字明显发软。字体已正确加载，景深关闭，768 像素宽的纸片纹理足够覆盖当前投影尺寸。

纸片、胶带与铭牌现复用已有的高清标签通道及场景深度。仅这些纹理使用最高 16 倍各向异性采样，
不再对文字施加原有的电影色调补偿。每张纸片保留一层普通印刷底图，共用同一纹理与形状，
避免较粗的深度遮挡边界露出空白纸底。高清层的深度比较对齐到场景深度像素中心，
消除倾斜纸面因采样错位产生的细条纹；原档案标签继续使用已有的深度路径。
没有增加纹理尺寸、渲染目标或动画循环。
纸片宽高、字号、镜头、场景性能档不变；增加的工作限于少量印刷平面与采样。
