# 莱茵调查板 · 第一阶段实装记录

日期：2026-09-18。对应 `rhine-agent-evidence-board-design-v1.md`。

## 已接通的工作链

1. `investigation_get` 读取当前会话的调查目录、已有线索、报告或来源编号。
2. LLM 根据调查目标选择 `investigation_open(new/resume)`；用户发新消息不会直接触发新建板。
3. 本地、云端、联网工具的真实返回登记来源。搜索摘要与已读原文分开保存，失败网页不记为已读。
4. `investigation_update` 增量添加、修订、关联或归并重要线索。Agent 不设置纸片坐标，不直接覆盖用户编辑过的正文。
5. `investigation_publish` 保存中央报告新版本，同时冻结当时使用的线索与来源。后续同目标追问可以继续原板。
6. `prts-investigation` skill 与原有 `prts-retrieval` 一起通过现有预设挂载；未改变检索资料范围。

## 场景与界面

- 保留透明悬浮操作层及原有性能档。研究板扩大在画面中的占比，中央固定报告位置。
- 六种卡面：原文摘录、研究发现、时间节点、关键关联、未解问题、交叉对照；款式与语义绑定。
- 调查标题、空板提示和分页固定在板面坐标，通过现有场景的相机投影同步透视、缩放、拖移和全屏视角；不再按视口百分比悬浮。操作栏沿板面铭牌排列，空板不显示无内容的下拉框与分页。
- 贴板矩阵禁用额外 CSS 过渡，避免减少动态效果模式下文字滞后一帧。复用现有帧回调，不增加渲染循环或调整性能档。
- 新卡按稳定槽位加入，轻微下移入场。已放置卡片不因新增线索而重排，手动位置优先。
- 每组最多 12 条线索；所有线索可通过目录及分页访问。中央报告不占这 12 个槽位。
- 查看中的板与 Agent 的工作板分离；用户查看旧调查时，提供返回当前工作板的入口。
- 单击线索查看解释与来源，双击编辑。保留拖动、缩放、连线与撤销重做；撤销按改动字段合并，保留后来新增的其他线索。
- 报告支持版本选择、引用定位及来源阅读。旧版本展示发布时的依据。

## 数据和恢复

以宿主 `storageDomain` 为唯一后台存储，每个会话一个隔离的 domain，使用 `single` 布局和真实 Zod schema。
整份会话调查记录在同一次原生提交中写入，避免线索、关系和版本号部分成功。
更新采用知识 revision；拖动使用独立 layout revision。请求带持久幂等回执，写失败不推进版本。
每个 Agent 运行绑定真实 turn；停止、失败或重启后保留已写入内容并结束运行状态。
界面使用已有认证 RPC 的可取消长轮询，只在保存成功后更新。

旧浏览器板中用户创建、修改过的内容一次性迁移；未编辑的剧情示例不进入真实调查。旧浏览器记录不删除。
冲突或同步失败时保留编辑草稿并显示可复制内容。

当前界限：每会话 128 块板、4096 个来源、每板 512 条线索/128 版报告、会话总记录 32 MiB。
达到界限时显式失败并保留已有数据，不偷偷丢弃内容。

## 每块调查板的重点证据盒（2026-09-19）

按用户确认的三层流程落地：档案架负责资料回查，板旁的小桌与证据盒保存待细读、比较、整理的重点材料，证据板保存已经写成的线索与报告。重点程度不被用来推断来源真实性。

场景与操作：
