# 莱茵生命资料馆

当前实现与真正 RhineLabUI 原版的同视角提交量、资源及内存对照见 [性能评估](rhine-upstream-performance.md)。早先“23,556 → 6,130”只描述插件自身内构烘焙阶段，不能作为相对原版的降幅。

资料馆作为 `rhine-lab` 皮肤加入现有插件，复用资料包、检索与读取内核。更新插件后
重启或重新加载 Harness，在 PRTS 语料设置中选择该皮肤。对话输入栏的「资料馆」打开
浏览空间，「返回对话」回到原会话。

白板场景实拍与验证见 [手动证据白板预览](verification/rhine-evidence-board/README.md)。
屏幕边缘入口的截图与操作检查见 [边缘切换场景](verification/rhine-scene-edges/README.md)。

## 操作

- 底部的「检索阵列 / 证据板 / 档案收录架」移动同一场景的镜头。证据板是一块实体白板，
  抬高后置于检索阵列和档案架之间，沿用原版暖白与浅灰材质；三区持续可见，镜头按空间顺序平滑移动。
  屏幕左右边缘的细箭头也可前往相邻场景，旁边显示目标区域名称；顺序为「检索阵列 → 证据板 → 档案收录架」，首尾不循环。
  桌面入口位于两侧中段，窄屏略向上移；支持鼠标、触摸点击及 Tab 后按 Enter/空格。
  拖到边缘松手、从边缘拖出再回来、快速双击都不会意外连续跳转。白板全屏、阅读、弹窗及待放置/连线时隐藏入口，切走前保存编辑中的线索。
  纸片由图钉固定，红绳展示手动建立的关联；左键拖动纸片整理位置，点选后编辑、连接或移除。
  在空白处按住鼠标左键拖动，可以像画板一样平移视图；按住空格再左键拖动，或按住鼠标中键拖动，
  可以从纸片上开始平移，不会改动纸片位置。
  滚轮向前放大、向后缩小，范围为 1–3 倍，朝鼠标指向的线索靠近；白板右上角贴在板面的薄铭牌也提供 `− / 比例 / ＋`，
  点击缩放比例或双击空白处恢复全貌。铭牌文字和按钮命中区域跟随板面透视与缩放，只有离屏时才恢复常规按钮并停靠到视口边缘。
  浮窗继续正常滚动，拖动纸片、平移视图与镜头换区时不响应缩放；切换区域后保留本次证据板视角，刷新页面恢复默认视角。
  点击板角铭牌的「全屏」，镜头切到白板正面，板面适配整个窗口，品牌、场景导航及周边阵列和档案架暂时收起，仍可平移、缩放和编辑线索。
  窄屏全屏时，镜头按底部编辑抽屉上方的可见区域取景；收起或展开抽屉后同步调整，纸片坐标保持。
  这里使用窗口内的专注视图，不调用浏览器全屏 API。原位的「退出」恢复进入前的视角；切换区域或会话也会退出。
  点击笔托左侧粉笔盒打开「整理线索」浮窗；标题栏可拖动，移动后留在选定的屏幕位置，窄屏使用底部抽屉。
  粉笔盒是一只半开的浅纸色小盒，五支短粉笔并排放在盒内；不再有盒下悬浮标签或矩形 hover 框，键盘访问和实体点击仍保留。
  粉笔盒离开画面时，板角出现「工具」入口。点选纸片在同一个浮窗编辑，返回「全部工具」选择短便签、疑问签、资料卡或关键词标签。
  标题栏「收起」将编辑窗折叠为小条并保留选中的纸片，点击「展开」继续编辑；「×」关闭工具并取消选择。
  选中纸片后，可用编辑窗「纸片大小」的滑杆或 `− / ＋` 等比调整到原大小的 50%–200%，点击「原大小」恢复 100%。
  也可直接拖动选中纸片的右下角等比缩放，拖纸片中部仍移动位置；旋转纸片必要时降低实际放大上限，调整后仍完整留在板内，图钉与红绳端点同步跟随。
  新建先显示半透明预览，在板面空白处点击放下；关键词标签只显示一行标题，短便签显示摘要，完整正文仍可在浮窗查看和编辑。
  「红绳连线」先点起点，再点另一张纸片建立关联，中间显示跟随鼠标的暗红虚线；重复与自身关系不会新增。
  已选中纸片时，点击「从此处连线」或按 `L` 直接以它为起点，再点目标即可；取消连线保留原选择。
  「复制」或 `Ctrl/Cmd+D` 在附近生成保留正文、来源、样式与尺寸的副本，副本不继承红绳。
  关联列表可以断开连线，更多操作中可以移除线索。工具窗「撤销 / 重做」覆盖新增、复制、移动、缩放、编辑、连线、断开、移除和清空示例。
  一次拖动或滑杆手势算一步，连续文字编辑合并；历史有数量上限，只在当前打开的会话内保留，切换会话或刷新后重置。
  `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做；输入框中保留浏览器原有的文字撤销。
  Esc 按层级先移开输入焦点，再取消正在进行的拖动、缩放、放置或连线，再关闭浮窗，最后退出全屏；搜索和阅读弹层优先处理自己的退出。
  阶段是线索属性，不限制白板的自由布局。当前最多 12 条线索，浏览器按会话保存内容、位置、大小、展示样式与关联；旧纸片布局保持。
  初次打开的六条《孤星》剧情研究示例由意象照片、关系图纸、档案页和短便签组成，
  [文案有对应剧情章节依据](rhine-lone-trail-copy.md)，可一键清空，清空不会删除已编辑的线索。
  左下角保留区域名称和线索数量，目录及清空示例收在浮窗的更多操作中。
  搜索结果和阅读器的「置入证据板」保留资料标题、来源身份与搜索摘要；不改变 Agent 已读状态。
  当前实现手动整理功能，Agent 写入证据板和新的检索暂存／归档流程留待后续接入。
  交互与资源边界见 [白板工具设计](rhine-board-tools-design.md)。
- 顶部导航可以新建对话和切换历史会话；提问框旁的 MODE / MODEL 选择模式与模型，
  直接使用 DSH 当前账户的配置。空白对话可切换模式；已有内容的对话使用「用此模式新建对话」。
  新对话继承当前工作区、模式和模型，配置完成后才进入。模型切换用于后续请求。
  Agent 工作时，输入栏提供「停止当前任务」。独立预览不显示这些会话操作。
- 主界面的 ASK THE ARCHIVE 输入可直接向当前会话提交问题，也可手动检索。
  ARCHIVE INDEX 打开真实资料目录；输入关键词搜索。点击结果阅读或收入档案架。
  手动浏览不会改变 Agent 的读取记录。
- Agent 检索期间使用原版完整切档动作：整排轨道移动、肩部起伏、带波谷的扩散波与选档抬升。
  每次切换留出弹簧收束时间；普通鼠标悬停不打断，点击、滚轮或方向键操作后暂停自动选档。
  每次真实读取按工具调用编号触发抽出，快速完成和同文档重复读取也有完整抬升、停留与归位。
  新结果按批次抽取真实资料送往档案架，同屏最多两个动作，不受当前二十四槽页限制；全部结果立即可读，
  大批量入库不会让动画积压数分钟。状态仍分别标记找到、已读、已引用；收藏另有标记。
- 档案架上下两层、每层十二槽，每页共二十四份；滚轮或按钮逐份翻阅，横向滚动或分页按钮换页；完整资料目录
  可按标题、来源或内容筛选全部已归档资料，显示当前范围与总数。
  模型使用原版尺寸与位置的工业铭牌：上排动态显示资料名与类型，下排保留品牌、编号与共享标志。
  下层先向开放的前沿水平滑出再转向阅读位置；新资料从架外下降到目标层后水平入架。
  阵列、架上、抽出和归位档案的盖板直接采用 0.025 粗糙度的清晰状态，不播放自动解密或回磨砂。
  架上边框仍采用普通阵列的不透明材质；360° 查看器保留手动清晰／磨砂切换。
  右下角按钮控制同一场景内的镜头平移。新资料到达时保持页码、选中文件、
  当前正文节点和滚动位置；模型先选中，再次点击打开正文。
- 主界面显示真实问题、工具阶段和本轮来源计数；整场会话的资料持续保留在档案架。
  只有 Host 确认正常结束才显示调查完成，中断和部分回答分别标示。完成后报告入口
  提升到资料摘要之前，阅读或翻阅档案架时提供完成提示，不自动切走当前页面。
  调查报告按 Markdown 排版，提供章节目录和本轮引用；打开原文后可以回到报告的
  阅读位置。流式更新保留已经阅读的段落，不主动拉走滚动位置。
- 阅读器可跳到命中处、Agent 已读范围或开头，长文分页。金色为相关命中，绿色
  仅对应实际 `corpus_read` 返回行。搜索命中不等于已读全文。
- 选择正文后保存摘录，提交时附标题、定位、版本及可用行号。单条最多 12,000 字，
  共 24 条；一次发送最多 22,000 字，超出时提示减少摘录并保留原内容。
- 调查记录展示工具返回正文。可以展开更早记录，也可继续从 Host 加载历史。
  旧工具结果没有结构化来源时仍可查看返回记录。

手动资料与摘录按会话保存在浏览器本地，最多保留 150 份手动资料。Agent 来源由
Harness 持久化会话日志恢复。旧版本来源不会自动跳到新版同名文章；读取失败时
保留已返回摘录。云端无本地定位时展示返回片段。

独立预览只提供本地搜索和读取，Agent 提交显示为会话中启用；Agent 调用使用
Harness 当前会话配置。预览不生成模拟检索、回答或演示档案。

| 部分 | 文件 |

| 白板、粉笔盒、纸片、红绳与临时预览 | `ui/rhine/evidence-board-scene.ts` |

| 报告正文排版 | `ui/rhine/report-markdown.ts` |
| 真实资料分类、稳定顺序与状态合并 | `ui/rhine/catalogue.ts` |
| 搜索、阅读、摘录、记录 | `ui/rhine/workbench.ts`、`workbench.css` |
| 来源展示元数据 | `src/archive-presentation.js` |
| 目录 RPC 与固定资源路由 | `src/ui.js` |
| 只读本地预览 | `bin/preview-rhine.mjs` |

`prts-archive-sources-v1` 展示元数据在工具执行时捕获版本，并随 Host 的 JSON 快照
持久化。身份为 `document:<data_version>:<document_uid>`，合并同一版本的云端锚点
与本地读取。保留原有 `prts-corpus-read-v1` 契约。嵌套调用进入检索状态与返回记录；
无元数据时不从标题猜测原文身份。

`operations` 逐次保留本轮工具调用的稳定编号、状态、真实定位和返回来源；并行调用与已完成
调用均参与场景调度。打开历史会话不会重播已完成操作，模型加载期间新收到的结果仍会播放。
短读取不依赖瞬时 `phase`，无明确定位时仅使用无编号的读取机构，不增加资料或已读计数。

`archive.search` 和 `read` 通过 `/api/prts-corpus/rpc` 共享 Fetch 通道传输，遵守
启用游戏、取消与版本校验。Web 另有兼容路径。脚本、样式、模型使用固定白名单；
资料以纯文本插入 DOM。用户点击提交后才将问题与摘录加入当前会话队列。

## 原版视觉基准

当前以 RhineLabUI 原版为基准，保留它的三维主体、MiSans 四款原始字体、长焦相机、
288 个档案槽位、物理外壳和灯光。阵列的复杂内构在加载时离屏烘焙成共享的
1024×740 贴图；选中、抽出、归位、Agent 运动档案及独立查看器继续使用完整实体。
架上静止档案保留原外壳、名牌、边缘刻线和螺丝，把内部组件替换为共享的斜视角烘焙贴图；
聚焦抬起、抽出、归位、入架、镜头移动及观察角度偏离时恢复完整内构，避免平面贴图暴露视差。
阵列按螺丝在屏幕上的尺寸切换两级外圈细分，保留凹槽、轮廓、外壳和文字，使用滞回阈值防止闪烁。
下方螺丝与立体文字还按当前视角做部件级画外和遮挡剔除：只用真实不透明基板证明遮挡，
邻居移走或部件重新露出时当帧恢复。说明和对照见 [阵列动态遮挡剔除](rhine-array-occlusion.md)。
盖板与边框已进一步分区，细字使用签名绑定的预烘焙贴图，小尺寸螺丝继续减少外圈细分并保留实体刻纹。
实现、画面对照和 CPU 代价见 [阵列主体优化](rhine-array-body.md)。
阵列保留全部逻辑槽位，但提交时排除被实体接管的槽位，并按当前相机对完整卡体做视锥剔除。
盖板与贴图共用可见列表；画外仍有效的投影基板保留，每帧只刷新一次动态阴影，供后处理复用。
检索结果到达后立即更新资料列表，架上模型与标签纹理按帧逐个准备，避免一次创建整页模型。
抽取和归位共用预先准备的完整模型，回收后复用其材质与独立编号纹理；架上模型另设缓存，
保留其边框材质。准备队列随隐藏暂停，换页或切会话取消过期项，退出时释放缓存。
原版的五列分类、每列档案循环、滚轮/方向键/触摸切换、选中抽出和滚动编号沿用原有实现。
现在只保留固定性能档：100% 渲染比例、1 倍像素密度上限、SMAA、1024 阴影、AO 与景深关闭、
透射分辨率 0.5、各向异性 4。画质按钮和设置弹窗已移除；旧的浏览器画质记录不再读取，
新开、刷新或重新打开均使用同一档。舞台缩放及像素密度改变时三维缓冲仍同步调整。
档案标签与证据板纸片的印刷面共用已有的最终分辨率文字通道，避免小字经过低分辨率场景放大和后处理后发糊；
只对这些印刷纹理采用最高 16 倍各向异性采样。旧纸片尺寸、字号和全场景性能档保持，复用场景深度处理图钉、红线与纸张遮挡。
新建紧凑便签与关键词标签使用 512 像素宽贴图，原有纸片继续使用 768 像素；放置和虚线预览不重画纸片纹理。
纸片大小通过独立的 `scale` 字段按会话保存，缩放时复用原有 512/768 像素贴图，不随倍率重画或重建纹理。
板角铭牌用四角投影将 `320 × 45` 的 DOM 映射到白板 X `[3.67, 7.37]`、Y `[3.80, 4.32]`，不增加渲染器或动画循环。
粉笔纸盒尺寸为 `1.02 × 0.48`，五支粉笔长 `0.40–0.45`、直径约 `0.096`，共有 11 个实体拾取对象；
盒中心锚点为 `(-3.8, -4.20, 0.48)`，纸盖文字沿用高清印刷通道。
档案架视图保留全分辨率透射，避免完整内构发软；返回阵列恢复性能档透射 0.5，
360° 查看器同样采用固定性能参数。实际参数与基础参数分别记录在 `renderQuality` 和
`requestedQuality`。画质收拢见 [固定性能画质](rhine-performance-only.md)，后续实现见
[静止档案贴图与阵列细节 LOD](rhine-static-lod.md)。
此前清晰度的定位与取舍保存在 [阵列边缘清晰度](rhine-edge-clarity.md)、[档案架清晰度](rhine-shelf-clarity.md)。
后续性能优化以保持页面构图、档案滚动及抽取动作一致为前提。

重新加载页面即可使用阵列贴图版本。在页面地址增加 `?rhineArray=geometry`（已有查询参数
时增加 `&rhineArray=geometry`）可对照插件完整内构阵列，仍使用固定性能画质。烘焙或半浮点读回
不可用时自动恢复实体阵列。贴图保留 CPU 像素用于 WebGL 上下文恢复，退出时释放。
当前烘焙光照和动态接收阴影为近似，阵列局部明暗可能与原版有差异。
增加 `rhineCull=off` 查询参数可关闭视锥剔除用于对照，仍保留实体所有权压缩与每帧阴影复用。
`rhineWorkbench.stats().arrayVisibility` 记录有效槽位、镜头内保留数、剔除数及各批次提交数；
`archiveCount` 仍表示 288 个逻辑槽位。`arrayVisibility.lod` 记录阵列高低细节实例数；
`shelfInterior` 记录共享烘焙资源和架上贴图／实体数量。加入 `rhineShelf=geometry` 可对照架上
完整内构，`rhineLod=off` 可关闭阵列螺丝 LOD。当前没有裁掉盖板下半部，也没有整体外壳多档减面。
`rhineOcclusion=off` 关闭新增部件剔除；`arrayVisibility.occlusion` 区分遮挡剔除和部件画外剔除。
`collectionResources` 与 `preparation` 分别记录模型创建／复用、备用数量及分帧准备进度；
`physicalFiles` 表示当前已经准备好的架上模型数量，资料总数仍由 `sourceCount` 表示。

上游场景和相关模块位于 `ui/rhine/original`，界面适配器保持宿主 CSS 隔离。
原项目的 40 份演示档案已移除；物理循环槽位只负责复用几何，不是资料记录。
首页分类为角色、剧情、世界、时间线与云端资料，数量来自真实目录或检索结果。
实际资料数量可超过物理槽位数，导航保持连续方向。主界面围绕当前调查重新排布。

浏览器检查覆盖同列前后循环、五列环绕、原版尺寸布局、真实资料读取、Agent 更新
期间阅读位置保持、隐藏与退出时暂停/释放、无 WebGL 阅读回退。Linux 本机只有
SwiftShader 软件渲染，不能以本机渲染速度代表硬件 GPU 表现。
