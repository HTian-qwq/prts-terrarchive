# 文档标题铭牌

铭牌绑定实际资料的 `id`、`title` 和编号。阵列当前盒子、档案架、检索搬运实体、回落副本和独立模型查看器使用同一套排版。点击当前盒子上实际可见的铭牌，可以打开对应资料。

按原版恢复实体形态：

- 尺寸 `0.99 × 0.46`，位置 `(-1.36, 3.04, 0.255)`，对应 RhineLabUI 原有封面铭牌。
- 铭牌相对盒面的旋转始终为零；阵列、抽出、回落、档案架和独立查看器都贴合原位置，不随视角翻起或抬升。
- 排版采用用户选定的 A「原版工业铭牌」：暖灰底色、柔和深灰文字和细横线。标题使用 MiSans Demibold，名称与文档类型同字号、同基线，斜线用更浅的颜色和常规字重。标题位于贴图上方可见区域，编号、RHINE LAB 和无限标记保留在下方。
- 标题字号固定为贴图中的 144 px，基线为 216 px；保持单行，不再将“干员语音”等类型放进会被前方盒子遮住的第二行。长名称优先省略名称尾部，尽量保留完整类型；没有可分离类型或类型本身过长时，整行省略。资料身份和右侧完整标题不受影响。
- 贴图调整为 `1536 × 714`，宽高比匹配原版铭牌，避免文字被拉长。保留高清文字和真实资料绑定。
- 撤去此前为悬浮宽标签增加的顶部雾化调整，恢复原来的阵列氛围遮罩。

模型和字体同时加载；字体失败时使用系统中文字体。贴图和材质归各自模型所有，仅在文字或资料身份改变时重绘。回落副本保留原资料标题，模型复用时更新标题与身份。空闲帧不重绘或上传文字，也不再更新铭牌的独立姿态。每张纹理基础像素数据约 4.18 MiB，mipmap 额外约三分之一；数量沿用既有实体池上限。

铭牌仍然只有两个三角形。主场景的铭牌移至独立图层，在 SMAA 和输出转换之后绘制，避免细字再次被场景抗锯齿柔化。最终画布按可见 CSS 尺寸的两倍采样，受既有像素总量和设备尺寸上限约束；场景的着色、透射、阴影、后处理与 LOD 判定继续使用性能档的原有分辨率。铭牌纹理的各向异性过滤提高到设备支持的最高 16 倍，其余纹理仍沿用性能档。

遮挡复用主场景已生成的深度：两个交替的 composer 目标配置深度纹理，在 beauty pass 后增加一次全屏深度拷贝，保存后续后处理可能覆盖的深度。最后只绘制可见铭牌，并用该深度丢弃被前方盒子遮住的片元；不重复绘制整套模型，也不读取 GPU 像素到 CPU。静止帧不新增文字上传。独立模型查看器继续沿用自己的渲染管线，但共享新的字体排版和文字纹理采样设置。

新增成本包括最终画布的像素带宽、主场景分辨率的一张 RGBA 深度拷贝纹理（每百万像素约 3.81 MiB），以及深度附件从渲染缓冲改为可采样纹理；不能据此宣称帧率完全不变。深度纹理和拷贝目标随 composer/铭牌渲染器释放，模型文字纹理仍遵守既有池的所有权。350 ms 导航限速和最多三份手动回落副本的保护维持生效。

实现：`ui/rhine/original/archive-label.ts`（尺寸、位置、排版），`ui/rhine/original/label-renderer.ts`（清晰铭牌与深度遮挡），`ui/rhine/original/quality-renderer.ts`（场景与输出分辨率），`ui/rhine/original/scene.ts`（纹理所有权和点击），`ui/rhine/scene.ts`（资料绑定）。

字体和真实 WebGL 遮挡验证在 `docs/verification/rhine-label-sharp/`，其中的双行粗体排版已由 A 方案替代；A 的验证脚本位于 `docs/verification/rhine-label-a/`。`rhine-document-labels-flush/` 对应文字清晰化前的原位铭牌验证，`rhine-document-labels/` 则对应已撤去的宽标签版本；验证截图不再归档。验证浏览器使用软件 WebGL；完整场景在稳定状态等待时暂停 GL 绘制，截图恢复真实绘制，不作为用户设备帧率测量。

清晰渲染管线已通过 61 项相关测试（标题、模型池、导航、LOD/剔除、性能采样、延迟准备和资料绑定）。当时浏览器确认在 1200 × 750 窗口中，主场景维持 1200 × 750，最终铭牌输出为 2400 × 1500，可见上沿可点击并打开同一文档。A 方案继续使用同一渲染管线，仅修改文字绘制及所预加载的字体字重，已重新构建并通过 18 项标题、模型池、导航和原版约束测试。

A 方案浏览器验证已完成：使用真实的“阿米娅 / 干员语音”资料，确认名称、斜线、类型均在同一条上方基线上，文字未超出铭牌；已查看阵列和抽出近景截图，文档类型完整露出。点击铭牌可打开同一资料，脚本及着色器无错误。测试窗口为 1600 × 1000，主场景和最终输出分别保持 1600 × 1000 与 3200 × 2000。报告保存在 `docs/verification/rhine-label-a/`，验证图片不再归档。

独立 GPU 用例分别验证了两个交替深度附件、后处理写深度之后的遮挡、盒子前后位置交换后的显露。只在此测试里读取像素断言颜色，产品路径没有同步读回。该测试每帧提交 9 个三角形，证明铭牌阶段未重复提交完整场景；真实场景细节视图的三角形计数较清晰化前增加 1，来自全屏深度拷贝。
