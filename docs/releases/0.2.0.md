# 0.2.0

终末地官方资料新增独立工具 `corpus_i18n`，可查询名称、剧情台词、角色档案和资料库内容的官方多语言原文。

- 已有搜索结果可用标题或文档定位及中文行号查询；仅有原文时支持精确或片段反查。
- 默认隐藏内部文本 ID；同文不同译保留来源，缺失翻译明确返回状态。
- 支持 14 种语言；当前 1.5.3 资料附件包含 77,034 个文本 ID。
- 安装器支持版本绑定的本地化附件和完整性校验，旧资料包继续可用。
- 修复旧会话搜索游标的后续分页：保留旧排序顺序，避免把结果排名当作扫描位置。

需要安装带多语言附件的资料版本 `agent-corpus-v2-20260919-endfield-i18n-v2` 或更新版本。

验证：46 个插件测试文件全部通过；真实资料完成 17 项注册工具验收，全部 1,078,476 个语言字段值与来源表一致。
