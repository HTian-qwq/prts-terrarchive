# 线索板体验检查与改进

2026-09-16。范围是现有手动线索板；保留莱茵生命场景、贴板铭牌、纸片、图钉和红绳。

## 实际遇到的问题

在独立浏览器会话里操作了旧版白板：纸片调到 110% 后按 Ctrl+Z，尺寸仍是 110%；
选中一张线索后进入红绳工具，选择会被清掉，需要重新点起点。
390 × 844 全屏时，纸片中心在 Y 364–469，编辑抽屉从 Y 309 开始，整个白板被遮住。
这说明问题首先是操作步骤和反馈，不只是颜色或排版。

旧版实拍及数据保存在验证目录的 `experience/before-mobile.png`、`experience/before-report.json`。

## 和成熟画板的对照

| 任务 | 检查时的线索板 | 本次调整 |
| --- | --- | --- |
| 改变一张纸片的大小 | 必须离开纸片去拖浮窗滑杆 | 选中后拖右下角；滑杆保留精确控制 |
| 从 A 连到 B | 退回工具首页，再点 A、B | 从 A 的“从此处连线”或 L 开始，直接点 B |
| 纠正刚才的操作 | 仅部分删除操作可撤销一步 | 新增、移动、大小、编辑、关系和删除共用 40 步历史 |
| 继续整理相似线索 | 手动新建并复制内容 | Ctrl/Cmd+D 复制纸片，保留来源，不复制红绳 |
| 暂时让出板面 | 关闭编辑同时丢失选择 | 收起为标题栏，保留选择与缩放角标 |
| 手机一边编辑一边观察 | 编辑抽屉完全挡住白板 | 全屏相机适配抽屉上方空间；收起后恢复可用区域 |

Miro 从选中对象直接连接目标，并提供通用撤销/重做；tldraw 将选择、移动、缩放角标作为明确的工具状态。
本次借鉴这些操作习惯，视觉继续采用本项目的实体白板。
参考 [Miro 连线](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines)、
[Miro 撤销与重做](https://help.miro.com/hc/en-us/articles/360017730793-Undo-Redo)、
[tldraw 工具状态](https://tldraw.dev/sdk-features/tools)。
对照来自官方说明，没有将在线产品的操作性能作为本项目测量结果。

## 操作细节

- 单击纸片打开编辑，直接拖动只整理位置。按住过程中使用固定的相机投影，避免抽屉和相机变化把纸片拖偏。
- 右下角等比缩放，以左上角为基准；到达板面边缘时约束大小和位置。Esc 取消，松手保存。
- 一次滑杆拖动算一次历史，停顿后继续拖也不会拆成多步；连续文字输入合并。输入框中保留浏览器的文字撤销。
- Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做，也支持 Ctrl+Y；N 放便签、L 连线、V 回到选择，Delete 移除选中线索。
- 编辑、缩放或移动过的示例成为用户线索；“清空未编辑的示例”保留这些内容。撤销恢复示例身份及相应关系。
- 历史在当前打开的会话内有效，最多 40 步；刷新及切换会话清空历史。已保存的纸片、大小和关系仍按会话持久化。

## 当前边界

当前仍是最多 12 张纸片的场景式研究板。多选、对齐吸附、批量整理、线条端点直接改接以及触摸双指缩放，
尚未具备成熟通用画板的完整能力。这一轮先解决单张线索操作、可撤销性和编辑遮挡，后续扩展应继续沿用相同的手势与历史规则。

验证方法和本次实际结果见 [场景验证记录](verification/rhine-evidence-board/README.md)。
