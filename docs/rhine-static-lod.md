# 静止档案贴图与阵列细节 LOD

2026-09-12。目标是在静止档案外观接近现状的前提下减少绘制开销，抽出时使用完整实体。此处基线是上一轮已固定性能画质的插件；与真正 RhineLabUI 原版的对照仍见 [原版性能评估](rhine-upstream-performance.md)。

## 实现

架上档案保留原外壳、透射盖板、边缘刻线、螺丝及独立编号名牌。内部八个组件烘焙为一张共享的 774×1536 线性半浮点贴图，保留基板之外的文字和突出部件。贴图按档案架中心的观察方向生成，投影 UV 位于原基板正面；不是用一张图片替代整个盒子。

每份架上完整模型仍在池里准备好，显示时只切换内部组件和贴图的可见性。焦点抬起、抽出、归位、入架、架间镜头旅行均使用完整内构；观察方向的估算视差超过阈值时也恢复实体。进入贴图阈值为 2.5 像素，返回实体阈值为 3 像素。贴图与实体不同时显示。归位后仍被聚焦的盒子保留实体，取消聚焦且稳定后才能恢复贴图。

内部替代部分从 66,118 三角形降到 2,682，其中平面 2 个，其余 2,680 个是保留的文字和突出细节。包含外壳的静止盒子由 82,346 降到 18,910 三角形，均不计独立编号平面的 2 个三角形。1920×1080 档案架通常有 11 个盒子使用贴图，1 个聚焦抬起的盒子使用完整内构。

阵列增加基于屏幕尺寸的两级螺丝 LOD：直径小于 18 像素时减少外圈细分，大于 22 像素时恢复原细分。凹槽、内部刻印和外壳不减面；高低两批实例互斥，沿用逻辑槽位、实例压缩与拾取映射。每个阵列盒子从 6,130 降为 5,376 三角形。先前已有的阵列内构贴图和视锥裁剪继续使用。

普通减面会破坏螺丝凹槽，本次最终采用只合并外圆细分的方式。测试使用实际 GLB，比对原几何属性、包围盒、可见面是否出现空洞及正面浮雕深度。

## 外观取舍

初版贴图偏暗，原因是沿用阵列的统一阴影乘数，把正面的环境光一起压暗。架上正面背向产生阴影的主光，最终取消贴图平面的这项乘数；外壳和保留几何仍使用原来的阴影。阵列原有贴图参数不变。

最终对照保留了外壳轮廓、品牌名牌和侧边刻线。贴图包含烘焙光照，因此内部曲面的高光与视差仍有小幅近似；观察角度变化时宁可恢复实体，优先保持外观。截图差异是指定视角的检查，不能等同于所有设备和角度视觉完全一致。

## 成本与边界

新增一份共享半浮点贴图：GPU 含 mip 约 12.09 MiB，另保留约 9.07 MiB CPU 像素用于上下文恢复。完整 GLB、架上模型与独立材质仍然保留，主要收益是减少绘制三角形和批次；本轮没有减少 GLB 下载大小，也没有承诺内存总量下降。

烘焙在准备队列中执行一次，复用的盒子不重新烘焙。初始化开销仍存在，读回或上传失败时回退完整模型。切换表示不会重建模型、材质或编号贴图，退出时共享资源统一释放。

阵列当前只增加了上述细节 LOD；尚未按邻居遮挡裁掉下半部，未实现整体外壳多级减面，也没有完整的遮挡剔除系统。

后续已加入下方螺丝与文字的部件级画外／遮挡剔除，见 [阵列动态遮挡剔除](rhine-array-occlusion.md)。本页保留该改动之前的基线与数字。

## 验证与对照

验证脚本、绘制计数和构建信息保存在 [验证目录](verification/rhine-static-lod/)，同视角截图仅在本地生成。浏览器使用 SwiftShader，仅验证实际图像、提交量和状态切换，不据此换算真实显卡的 FPS。

同一固定性能配置，1920×1080、DPR 1；每个结果包含实际绘制的所有渲染阶段：

| 视图 | 修改前三角形 | 修改后三角形 | 减少 | 绘制调用前 → 后 |
| --- | ---: | ---: | ---: | ---: |
| 阵列 | 2,299,502 | 2,049,174 | 10.89% | 55 → 55 |
| 档案架 | 2,736,064 | 1,265,072 | 53.76% | 546 → 436 |
| 抽出近看 | 1,107,258 | 1,107,258 | 0% | 275 → 275 |

抽出近看时观察方向改变，其余架上档案也因视差保护恢复实体，因此该视角没有三角形收益。900×1200 窄屏档案架为 2,343,892 → 922,664，仍是 11 份贴图、1 份聚焦实体。上述数字是相对修改前插件，不是相对原版。

固定截图区域的平均 RGB 绝对差（0–255）：档案架整体约 0.17，最外侧正面约 1.86，阵列约 0.005。外侧正面的 95 分位差为 11，仍有局部高光与视差差异，不能只用整体均值代替目视判断。抽出后模型区域像素一致。原始区域坐标和指标见 [comparison.json](verification/rhine-static-lod/comparison.json)。

六个相关测试文件共 28 个用例、TypeScript 检查、生产构建通过。浏览器验证七个状态；对正常聚焦、抽出、归位、取消聚焦共记录 300 帧模型状态，运动阶段始终使用完整内构。模型创建数始终为 15（12 份架上模型和 3 份活动备用），无浏览器错误。这里只执行相关渲染与模型回归，未重跑整套宿主业务流程。
