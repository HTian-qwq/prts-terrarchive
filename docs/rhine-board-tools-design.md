# 白板工具与紧凑线索设计

2026-09-16。白板工具已接入正式三维场景；此文档记录最终交互与实现边界。
`work/board-tools-design/board-tools.html` 保留为早期交互草案，当前画面以
[正式场景验证](verification/rhine-evidence-board/README.md)为准。
视图按钮、记录工具和线索都围绕白板布置，继续沿用莱茵生命暖白、银灰、淡香槟与暗红细绳的视觉。

## 交互依据

本次体验调整参考官方资料中的三个行为：从选中物件直接建立连接（[Miro Connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines)）、
有限的会话内撤销与重做及对应快捷键（[Miro Undo/Redo](https://help.miro.com/hc/en-us/articles/360017730793-Undo-Redo)）、
将物件选择、角落缩放与画布平移作为独立手势状态（[tldraw Tools](https://tldraw.dev/sdk-features/tools)）。
这些资料用于行为对照，视觉继续使用实体纸片、图钉、暗红细绳与粉笔盒。

## 白板上的布局

- **右上角：贴在板面的视图铭牌。** `− 100% ＋` 与 `全屏` 合并为一条暖白薄铭牌，和左侧 RHINE LAB 铭牌形成平衡。
  百分比可点击恢复全貌，全屏后原位显示“退出”。文字、边缘和实际按钮命中区域一起服从白板的透视与缩放。
  控件仍是可交互 DOM，以四角投影矩阵贴合板面；正常视角不再使用始终朝向屏幕的悬浮按钮。
- **下方笔托：粉笔盒。** 左侧放置 `1.02 × 0.48` 场景单位的浅纸色小盒，半开纸盖印 `RHINE / CHALK`。
  五支短粉笔沿盒深并排并稍微错开，长度 `0.40–0.45`、直径约 `0.096`，四支暖白、一支暗红，采用粗糙哑光材质。
  盒体、粉笔和轻微接触阴影都属于现有三维白板。点击盒子或粉笔打开整理工具，第二次点击收起。
  盒下不再悬挂“整理线索”标签，也不显示矩形 hover 框；保留不可见的键盘命中区和实体拾取。
  右侧板擦保留为场景装饰。
- **悬浮工具窗：按需打开。** 宽约 280–300 CSS px，暖白实底、细边、轻投影和可拖动标题栏。
  首次在粉笔盒附近的可用空白处打开；移动后留在用户选定的屏幕位置，镜头平移不再带着它移动。
  标题栏显示 `FIELD TOOLS / 整理线索`，首屏为短便签、疑问签、资料卡、红绳连线，另有一条低强调的“关键词标签”。
  选中纸片时，同一个窗口切为编辑内容；全部工具和编辑内容共用一处窗口。
  标题栏「收起」折叠为显示所选纸片标题的小条，选择状态保持；「展开」恢复编辑，「×」关闭并取消选择。
- **左下角原操作栏。** 保留简短的区域名称和线索数量；将新建、连线和编辑集中到粉笔盒，目录、清空示例放入工具窗的低频操作区。
  “检索资料”仍可复用全局档案索引，在资料卡工具中给出入口。

## 标签的视觉层次

“更多标签”包含两件事：更丰富的紧凑外观，以及能够放置更多短线索。外观与内容含义分开。

| 样式 | 适用内容 | 外观 |
| --- | --- | --- |
| 关键词标签 | 人物、地点、待核对、重要转折 | 窄纸条，一行标题，单枚图钉 |
| 观察便签 | 一条发现、读数或时间关系 | 暖白横纸片，标题和两三行摘要 |
| 疑问签 | 尚未解释的矛盾和问题 | 淡赭短签、小问号，沿用现有疑问语义 |
| 资料卡 | 原文摘录与来源 | 偏白竖纸、细侧标，明确保留来源 |
| 阶段结论 | 整理后的阶段性判断 | 使用便签外观，通过研究阶段属性标注结论 |

新建先显示半透明纸片预览，由用户在板面空白处点击放置。
短标签只控制板面摘要与尺寸，完整正文、来源、关联和阶段仍保留。较长内容在编辑窗查看。
不为每张纸增加装饰图，保留板面空白，让重点由大小和关系表现。

## 交互规则

1. **默认浏览。** 空白左拖平移，纸片左拖移动，滚轮缩放；空格加左键和中键可以从纸片上平移。
   按住拖动只选择和整理纸片，不自动弹出编辑窗；单击后再打开编辑。移动过的示例会成为用户线索，清空未编辑示例时保留。
   打开粉笔盒只打开工具窗，不切断这些操作。
2. **放置线索。** 选纸片类型 → 板面上预览 → 点击空白处放下 → 同一个窗口编辑。
   未放置前不写入数据；Esc 取消预览。板面之外点击不新增。
3. **直接连线。** 选红绳连线 → 点 A → 暗红虚线跟随鼠标 → 点 B 建立实线。
   第一张图钉高亮，显示“再点一条线索”；连完一次回默认模式。重复关系与自身关系不新建。
   已选 A 时，点击编辑窗「从此处连线」或按 `L`，再点 B 即完成；Esc 取消后保留 A 的选择。
   连线期间普通左键不拖纸片，空格和中键仍能平移。无 WebGL 时使用编辑窗的关联下拉框。
4. **编辑内容。** 点击纸片，在浮窗编辑标题、正文；来源保留，研究阶段等低频属性折叠。
   「纸片大小」提供滑杆、`− / ＋` 和「原大小」，以原尺寸的 50%–200% 等比缩放；旋转纸片必要时限制实际最大倍率。
   选中纸片右下角显示缩放角标，拖动它直接等比调整，拖纸片中部仍为移动；取消手势恢复调整前的状态。
   纸片保持在可写范围内，图钉与红绳端点同步跟随，倍率按会话保存。
   现有自动保存继续工作；编辑中的草稿在选择另一张纸或切换会话前照旧处理。
5. **复制、断开与删除。** 「复制」或 `Ctrl/Cmd+D` 在附近生成新纸片，保留内容、来源、样式和尺寸，副本不继承连线。
   在选中纸片的关联列表中明确点“断开”，不把板擦直接绑定批量清空；删除收在更多菜单，也可按 `Delete/Backspace`。
   清空示例继续只针对未编辑示例，复制受 12 张总容量限制。
6. **撤销与重做。** 覆盖新增、复制、移动、缩放、正文与属性编辑、连线、断开、删除和清空示例。
   一次拖动或滑杆手势只记一步，连续文字输入合并，单纯选择与切换工具不占历史。
   工具窗常驻「撤销 / 重做」，支持 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`，以及 Windows 的 `Ctrl+Y`。
   历史有数量上限，只保留在当前打开的会话内，切换会话或刷新时重置；撤销后发生新修改会清除重做分支。
   输入框、文本域和可编辑内容保留浏览器自己的文字撤销；搜索、阅读弹层打开时不接管白板快捷键。
7. **退出层次。** 正在拖动或缩放时，Esc 先取消手势；输入中先结束输入焦点，随后取消放置或连线，再关闭工具窗，最后退出全屏。
   页面已有搜索/阅读弹层优先处理自己的 Esc。

## 投影、裁切与窄屏

- 铭牌 DOM 的基准尺寸为 `320 × 45`，对应板面局部范围 X `[3.67, 7.37]`、Y `[3.80, 4.32]`。
  相机投影四角后生成 CSS `matrix3d`，字号和命中区域随整个铭牌一起透视、缩放，不固定屏幕像素大小。
- 只有铭牌离屏时才恢复常规朝向的停靠按钮，留至少 16px 安全边距；返回板内后重新贴合板面。
  粉笔盒离屏时，板角补出小“工具”入口，编辑入口不会丢失。
- 工具窗拖动不能越过可见窗口边界；视口缩小时重新约束位置。窄屏使用底部抽屉，板角铭牌保留。
- 窄屏全屏时，按抽屉上方的实际可见区域取景；展开、收起与关闭抽屉均更新取景范围。
  相机调整不改动纸片位置，收起编辑窗后仍能拖动或缩放当前纸片。
- 原型在窄屏重排纸片以便观察工具布局；正式实现仍使用同一个三维白板，通过已有缩放与平移查看，不自动改写纸片坐标。
- 新增和连线模式、未落下的预览均为临时交互状态，不进入会话持久化数据。

## 正式实现边界

- `evidence-board-panel.ts` 管理四种新建模板、单一可拖动/折叠浮窗、自动保存、示例 ID 转换、会话隔离、关系去重和选中后的连线/复制操作。
- `evidence-board-history.ts` 管理有数量上限的撤销与重做快照、连续输入合并和会话切换清理。
- `evidence-board-model.ts` 保持三种内容类型，将展示样式作为独立可选字段；校验容量、正文、来源、位置和关系。
- `evidence-board-scene.ts` 管理粉笔盒拾取、板面坐标转换、纸片移动/角落缩放、实体红绳、临时预览和高清印刷面。
- `scene.ts` 管理空白平移、滚轮与按钮 1–3 倍缩放、全屏、复位、板角投影、缩放手势与抽屉上方取景。
- `workbench.ts` 将四角投影转换为板角铭牌的透视矩阵，管理粉笔盒键盘入口，并处理全屏、全局弹层和 Esc 优先级。

接口与资源规则：

- `RhineSceneOptions.onBoardAnchors(frame)` 传板角、粉笔盒以及铭牌四角的投影位置、是否可见与缩放值。
  挂在现有 `frame()` 的 `original.update()` 后，使用本帧最终相机。
- 坐标投影到 scene host 的布局尺寸，按钮层和 canvas 同处 stage，不再乘 DPR，也不重复乘 stage scale。
  尺寸只在 resize 时量取；位置变化不足半像素时不写 DOM。不要在每帧遍历 `stats()`。
- `setBoardTool({ mode: 'select' })`、`{ mode: 'place', template }`、`{ mode: 'connect', fromId? }`
  控制场景手势，`zoomBoard(-1 | 1)` 与现有滚轮共用缩放逻辑。
  场景只报告放置坐标和两个端点 ID，数据仍由现有面板/模型维护。
- 紧凑样式采用独立可选字段 `presentation: 'compact' | 'tag'`，与 `kind`、`stage` 分开。
  未携带字段的旧纸片继续原来的外观；不覆盖用户文字、位置或关系。
- 单张纸片倍率采用可选字段 `scale`，默认 1，按会话持久化；根据旋转后的四角约束倍率与位置。
  滑杆实时更新场景，结束调整后保存；关闭工具、切换会话及离开页面前提交待保存的尺寸。
- 右下角缩放采用板面坐标和手势开始时的相机，以纸片对角方向计算等比尺寸，松开后通过 `onBoardResize` 提交一次修改。
  缩放过程只在场景中预览；取消时恢复模型，历史恢复、删除或会话更新不能被尚未结束的预览覆盖。
- 面板通过 `handleShortcut(event)` 统一处理历史、复制和工具快捷键；`N` 新建便签、`L` 连线、`V` 返回选择模式。
  `onViewportInset(bottomFraction)` 将窄屏抽屉占用比例交给 `setBoardEditorInset`，由现有相机取景逻辑处理可见范围。
- 粉笔盒使用共享低面数几何体与粗糙材质，含 11 个实体拾取对象：底、四壁、五支粉笔与纸盖。
  局部锚点为 `(-3.8, -4.20, 0.48)`，盒底完整落在笔托内；盖面文字复用现有高清印刷通道，资源统一释放。
  板角局部锚点为 `(7.15, 4.055, 0.22)`；投影复制固定向量，避免改动模型坐标。
- 动态连线预览只用一条可更新端点的 Line；确认后才调用已有实体红绳重建。
  示例纸片编辑可能改变 ID，确认两个端点时必须通过已有 ID 映射解析。
- 切工具、离开区域、切会话、失焦、pointercancel 与 contextlost 时，统一清理预览、端点和指针捕获。

## 数量与性能边界

当前 `EVIDENCE_CARD_CAPACITY = 12`，六个默认示例计入容量。
容量、解析截断、关系数量与布局候选同步扩展；保留存储格式 v1 和原来的 100,000 字符总长度边界。
正文仍最多 4,000 字符，标题最多 120 字符，来源字段继续按原边界校验。

短便签约 `2.68 × 1.36`、疑问签约 `2.60 × 1.24`、关键词标签约 `2.40 × 0.56` 场景单位，
使用 512 像素宽纹理；原有纸片保留 768 像素宽度与旧布局。紧凑样式只裁切板面摘要，不截断已保存的正文。
可写范围为 X `[-7.55, 7.55]`、Y `[-3.82, 3.90]`，放置、移动和缩放均保证纸片角点不越界。
预览移动只更新位置、可见性及一条虚线的两个顶点，不重画纸片纹理或创建实体红绳。
纸片缩放复用原有 512/768 像素纹理，不重画或重建；内容变化才重画，类型或展示样式改变画布尺寸时重建对应纹理，退出时释放资源。
资源验收继续关注 WebGL renderer、后处理链、动画循环及纸片纹理是否按既有路径复用；本次体验调整的测量结果以验证目录为准。

## 验证记录

此前板面贴合修订已检查默认视角、120% 放大、正面全屏、1366px 舞台 CSS 缩放及 390px 窄屏的四角映射，
实测最大偏差小于 0.04 CSS px，测试阈值为 0.2 CSS px。缩放、复位、全屏、300% 离屏停靠和窄屏编辑入口均通过。
隐藏 DOM 命中区后，直接点击真实三维粉笔盒仍能打开工具窗；未出现页面或控制台错误。
该轮截图与报告见验证目录的 [贴板修订记录](verification/rhine-evidence-board/README.md#本轮贴板修订验证)。

上一版工具浏览器检查已覆盖粉笔盒开关、浮窗拖动、放置取消与纹理更新计数、紧凑标签和便签、
直接连线与示例身份转换、断线和删除撤销、300% 时磁贴停靠和工具入口回退、
全屏 Esc 层级、刷新恢复及 390 像素窄屏抽屉。
模型回归覆盖 12 张容量、最大内容存储预算、紧凑样式边界及六张旧示例布局保持。

12 张混合板补查确认满额时禁止新增；该测试组合使用 12 份卡片纹理、4 份共享或工具纹理，
卡片纹理合计 2,933,760 像素。1366 像素宽窗口中按钮保持 38 像素高是上一版屏幕朝向控件的行为，
不作为当前贴板铭牌的尺寸要求；当前铭牌随白板透视和缩放。
连线起点选择后中键平移再完成连线、长资料正文与来源身份保留、放置中切全屏取消也已覆盖。
上下文丢失后的目录添加与编辑、直接无 WebGL 启动时的真实资料置入、重复去重和会话隔离通过。
这些记录验证资源数量与交互结果，不代表实机帧率或更高容量的测量。
