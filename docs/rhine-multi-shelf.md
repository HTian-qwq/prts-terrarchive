# 双层调查档案架

2026-09-12：原单层十二槽改为上下两层、每层十二槽，一页二十四份。来源顺序先填下层，再填上层；页面中的上层槽位组显示在下层组上方，并在当前档案编号旁标明所在层。超过二十四份仍分页，全部目录保持完整。

`ui/rhine/shelf-layout.ts` 统一容量、层间距和槽位映射，供目录分页、场景和模型池使用。层距 4.6，原尺寸盒子顶部与上层托盘之间留空。两层托盘、导轨及四根立柱共享一个单位立方体几何体，并按三种材质实例化；架体每个常规绘制通道只需三个批次，阴影等额外通道会另计。

静止档案沿用现有的完整外壳和共享内构烘焙图，当前聚焦、运动或视角偏离过大的盒子继续恢复实体。模型池最多保留一页二十四个架上盒子，按帧准备模型和独立标题纹理，翻页复用。容量翻倍会增加架上盒子、材质和标题纹理的资源开销，不能把架体合批理解为整体渲染开销降低。

选中预览改为向开放的前沿探出。抽取时先水平退出架体，再转向阅读位置；关闭阅读沿相反路径回到原层。新资料运输先到架外、下降到目标层，然后水平入架，避免直接从上方穿过上层托盘。保留此前修复的阅读态可见性：只有当前被抽出的架上盒子显示，邻居隐藏；延迟构建后打开同样有效。

相机按两层实际高度取景。横屏增强左侧资料区的浅色遮罩，竖屏把可滚动资料面板放到模型下方，避免拉远后背景白板与正文重叠。阅读模型尺寸和原工业铭牌尺寸保持原值。

- 原有二十四项模型池、准备队列、来源合并、铭牌和阵列基础测试通过；新增槽位映射检查通过，共二十五项。池边界与分页断言更新为二十四槽。
