# 固定性能画质与 LOD 实施范围

2026-09-12。用户决定只保留性能画质，并核对此前讨论的 LOD 是否已经实施。

工作台固定使用当前性能参数：100% 渲染比例、DPR 上限 1、SMAA、1024 阴影、AO 0、景深 0、透射分辨率 0.5、各向异性 4。移除画质按钮、弹窗、预设选择和自定义参数事件；不再读取 `prts-rhine-quality:v1`。旧记录留在浏览器中但不影响运行，也不需要用户清理。新开与重新打开均采用同一配置，360° 查看器通过原有调用接收该配置。

档案架沿用上一轮清晰度修复：实际透射分辨率为 1、景深为 0，其余仍是性能参数。返回阵列恢复透射 0.5。窗口大小与 DPR 变化仍会更新渲染缓冲；盖板清晰状态、原品牌名牌和完整抽取动作不变。

底层 Three 场景的通用画质方法和原版参数定义保留，供内部尺寸计算与历史对照使用；产品 UI 不再提供其他档位。两个测量脚本改为只采集当前实际配置，不再寻找已移除的画质控件或自动切换参数。

## LOD 的实际状态

以下是画质收拢完成时的历史状态；之后的架上内构贴图和阵列细节 LOD 已在
[静止档案贴图与阵列细节 LOD](rhine-static-lod.md) 中实现、验证。

已实施的是阵列内构的共享贴图替代、视锥裁剪、有效实例压缩、每帧阴影复用，以及架上和活动模型的分帧准备与对象复用。阵列用贴图，选中与活动档案用完整实体，属于按状态切换表现的已有优化。

尚未实施完整的分级 LOD：按屏幕尺寸切换外壳精度、根据相邻档案遮挡只保留露出的顶部、架上静止档案使用简模并在抽出时切换高模。当前架上每份仍有完整内构；裁剪仅排除画外和被实体接管的槽位，不会把普通档案下半部几何动态剪掉。

本轮只收拢画质并澄清实施范围，没有把上述未完成的 LOD 宣称为已实现。下一阶段应围绕静止阵列／架上档案的简化表示，以及抽取、归位、首尾露面时的连续切换单独实施与验证。
